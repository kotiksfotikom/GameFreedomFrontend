# GameFreedom Frontend

Простий клієнтський інтерфейс (HTML + CSS + Vanilla JS) для взаємодії з бекенд API магазину ігор **GameFreedom** з підтримкою реєстрації, JWT-авторизації та розмежування прав доступу.

## Реалізований функціонал

- **Каталог ігор (`index.html`):** публічна сторінка, доступна всім відвідувачам без авторизації.
- **Реєстрація (`register.html`):** створення нового акаунта з валідацією полів на бекенді.
- **Логін (`login.html`):** отримання `access` та `refresh` JWT-токенів, збереження їх у `localStorage`, автоматичне повернення на сторінку, з якої користувача перенаправило, а також захист від відкриття сторінки входу вже авторизованим користувачем.
- **Додавання гри (`add-game.html`):** сторінка, доступна лише авторизованим користувачам. Неавторизованих користувачів автоматично перенаправляє на `login.html`.
- **Автоматичне оновлення токена та Logout (`auth.js`):**
  - при отриманні відповіді `401 Unauthorized` фронтенд автоматично оновлює `access` токен через `/api/accounts/token/refresh/` і повторює запит;
  - навігаційна панель динамічно відображає кнопки «Логін / Реєстрація» або ім'я користувача з кнопкою «Вийти»;
  - при виході (`logout`) збережені токени видаляються з `localStorage`.

## Як запустити проєкт

1. **Запустіть бекенд-сервер Django** (з репозиторію `GameFreedom`), щоб він працював на порту `8000`:
   ```bash
   python manage.py runserver
   ```
2. **Запустіть локальний HTTP-сервер для фронтенду** у папці цього репозиторію:
   ```bash
   python -m http.server 5500
   ```
3. Відкрийте у браузері: **`http://127.0.0.1:5500/index.html`**
