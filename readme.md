# GameFreedom Frontend

Простий фронтенд для демонстрації роботи API та налаштувань CORS.

## Як запустити проєкт

1. **Бекенд:** Переконайтеся, що бекенд-сервер Django запущений на порту `8000` (адреса `http://127.0.0.1:8000`).
2. **Фронтенд:** Відкрити файл `index.html` у будь-якому браузері (шлях формату `file:///...`).

Фронтенд робить GET-запит до `/api/games/` і виводить список ігор.
